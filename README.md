# MarketBot

MarketBot is a quantitative market intelligence platform focused on Indian financial markets.

## Objectives

- Collect market data automatically
- Preserve historical option chain data
- Build market intelligence models
- Generate probability-based trading insights
- Maintain a complete research database

## Current Modules

- Data Collectors
- Feature Engineering
- Analytics
- Learning Engine
- Market Brain
- Report Engine
- Dashboard

## Project Status

Current Sprint:

Sprint 1 - Cloud Infrastructure

## Requirements

Python 3.12+

Install dependencies

```bash
pip install -r requirements.txt
```

Run

```bash
python automation/run_daily_update.py
```
