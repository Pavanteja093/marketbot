# MarketSnapshot

Every AI model receives a MarketSnapshot object.

The snapshot represents everything MarketBot currently knows about one instrument.

Current fields

- symbol
- trade_time
- spot_price
- previous_close
- change_pct
- volume

Options Analytics

- pcr
- max_pain
- average_iv
- delta
- gamma
- theta
- vega

Price Structure

- support
- resistance
- trend

Market Intelligence

- market_regime
- market_bias
- confidence

Future

- breadth
- sector_strength
- india_vix
- fii_dii
- news_sentiment
- global_markets
